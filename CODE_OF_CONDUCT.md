# Code of Conduct

Fluxito adopts the [Contributor Covenant version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct, with the additions and contact details below.

## Our pledge

We as members, contributors, and leaders pledge to make participation in Fluxito a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

We pledge to act and interact in ways that contribute to an open, welcoming, diverse, inclusive, and healthy community.

## Standards

The full text of expected behaviour, unacceptable behaviour, and enforcement guidelines is the standard Contributor Covenant 2.1 text linked above. We adopt it without modification.

## Scope

This Code of Conduct applies in all project spaces — the GitHub repository, issue trackers, pull-request discussions, and any other forum the project uses to communicate. It also applies when an individual is officially representing the project in public spaces.

## Enforcement and reporting

Instances of abusive, harassing, or otherwise unacceptable behaviour may be reported to the project maintainers via the GitHub Security Advisory channel:

- https://github.com/digitalXperiments/fluxito/security/advisories/new

(GitHub Security Advisories support private disclosure to the repository maintainers; that's the same channel used for security reports — see [SECURITY.md](SECURITY.md). If you'd prefer email, open a regular GitHub issue requesting a private contact channel and we'll respond.)

All reports will be reviewed and investigated promptly and fairly. Maintainers are obligated to respect the privacy and security of the reporter of any incident.

## Enforcement guidelines

We follow the four-step Community Impact Guidelines from Contributor Covenant 2.1: Correction → Warning → Temporary Ban → Permanent Ban. The full text is at the link above.
